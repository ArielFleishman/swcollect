sw_raw relationship map

sw_raw keeps one table per SolarWinds entity and has no foreign keys between them on purpose: a raw row is never refused because its parent is missing. swcollect proves the connections against SolarWinds instead. This map shows every proven connection, the columns it joins on, and a ready-made JOIN. Every join also matches instance_id, because a NodeID belongs to one Orion server.
